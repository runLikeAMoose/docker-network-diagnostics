Background
Docker is a platform trusted by millions of developers for building, sharing, and running
containerized applications. We’ve become the industry standard for container tooling, with a
thriving ecosystem spanning individual developers, open source communities, and enterprises.
Docker Desktop is our flagship developer product—a cross-platform GUI and CLI tool that
enables developers to run Linux containers natively on macOS and Windows. It includes
everything needed to build containerized applications: Docker Engine, Kubernetes, Docker
Compose, volume & network management, and integrations with popular developer tools like
Visual Studio Code.
Docker Desktop plays a critical role in helping developers test and iterate on their applications
locally—before those applications reach CI or production environments.
Situation
Today, many developers run multi-container applications locally using Docker Desktop and
Docker Compose. These applications often require container-to-container communication,
access to external services, or port forwarding to the host (Docker runs in a VM on macOS and
Windows).
When something goes wrong—such as a container failing to connect to a database, a web
service not responding, or DNS resolution failing—developers are left with minimal tooling to
understand and resolve the issue. Common questions like the following are difficult to answer
with current functionality:
● Why can’t container A reach container B?
● Is the right port exposed and mapped?
● Is there a DNS or bridge network misconfiguration?
● Is traffic being blocked by a VPN or local firewall?
The current debugging experience relies heavily on manual inspection, trial and error, and
community workarounds. This results in lost productivity and a frustrating developer
experience—especially for new users or teams in more complex enterprise environments.
Problem Statement
Developers struggle to understand and debug networking issues when containers are unable to
connect to each other, the host, or external services. How can Docker Desktop help developers
more easily diagnose and resolve these issues?
